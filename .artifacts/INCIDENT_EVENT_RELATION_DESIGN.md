# 追加検討: IncidentLog と保護動画セグメント・関連イベントのフラット時系列表示設計

## 1. 課題と目的
一連の事故シーケンス（例：`接近` ➔ `減速` ➔ `衝撃` ➔ `音量`）において、従来は親子階層（ネスト）構造で表示するアプローチを検討していたが、ユーザービリティの観点から**「階層構造を廃止し、動画記録とイベント検知をフラットな時系列リスト（最新が一番上）として一元的に表示する」**方針に改訂する。

これにより、ユーザーは走行中の出来事と保護された動画セグメントを直感的なタイムラインとして把握できる。

---

## 2. フラット時系列タイムライン設計 (`MainScreen.kt`)

動画の記録（`IncidentLog`）と各検知イベント（`EventDetectionLog`）をマージし、`timestampMs` の降順（`sortedByDescending { it.timestampMs }`）でフラットに並べる。
