# ChariSafe Phase 3 UI モックアップ仕様書 (統合タイムライン対応版)

本書は、ChariSafe Phase 3 で導入される常時表示エリアおよび Accordion 形式折りたたみエリアの画面レイアウト構成を定義するものである。

---

## 1. 全体画面レイアウト構成

## 2. 常時表示エリアの詳細仕様

### 2.1 現在速度 (Speed Meter)
- **スタイル**: 文字サイズ 52sp, ボールド（視認性最優先）。
- **表示内容**: `24.3 km/h`

### 2.2 録画経過時間 (Recording Timer)
- **スタイル**: フォーマット `HH:mm:ss` (例: `01:15:42`)。録画停止時は `00:00:00` 表示。

### 2.3 最後のイベントカード (`LastEventCard`)
- イベント発生直後に自動更新される直近のイベントカード。
- 表示例: `🚗 接近 (2分前)` または `イベント発生なし`

### 2.4 イベント感度スライダー (`EventSensitivityCard`)
録画中であってもリアルタイムに変更可能。
- **減速感度**: `0.5秒` 〜 `3.0秒` (標準: 1.5秒)
- **接近感度**: `0%` 〜 `100%` (標準: 70%)
- **衝撃感度**: `2.0G` 〜 `5.0G` (標準: 3.0G)
- **音量感度**: 振幅閾値 `1000` 〜 `10000` (標準: 5000)

### 2.5 構造化イベント件数サマリーカード (`EventCountSummaryCard`)
- 減速、接近、衝撃、音量の累積件数を 4 つのグリッドカードで表示。
- カードをタップすると「▶ 📁 走行ログ タイムライン」アコーディオンが開閉展開。

---

## 3. 折りたたみエリア (Accordion) 仕様

### 3.1 ▶ 📁 走行ログ タイムライン (`AccordionItem`)
- 保護された録画セグメント（動画ファイル）と、その時間内に発生した各種イベント（減速・接近・衝撃・音量）を統合したネスト時系列で表示。
- イベントタップで該当動画位置の特定および地図表示が可能。

### 3.2 ▶ 📈 ライドサマリー & 速度グラフ
- 危険度指標（距離あたり・時間あたりの発生件数）を一覧カードで定量化表示。
  - **接近**: 12件 (`0.42件/km` | `3.6件/h`)
  - **減速**: 3件 (`0.11件/km` | `0.9件/h`)
- キャンバス速度グラフ上にイベントマーカープロット。
