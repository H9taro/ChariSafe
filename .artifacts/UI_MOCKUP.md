# ChariSafe Phase 3 UI モックアップ仕様書 (順序統一版: 接近→減速→衝撃→音量)

本書は、ChariSafe Phase 3 における「イベント履歴の日付別グルーピング表示」および「アプリ全体でのイベント種類の順序統一（**接近 ➔ 減速 ➔ 衝撃 ➔ 音量**）」を反映したUIレイアウト構成を定義するものである。

---

## 1. 📁 イベント履歴画面（日付ごとのグルーピング表示）

イベント履歴画面では、大量ログが見やすくなるよう**日付（例: `2026-10-26`）をセクションヘッダーとしてグルーピング**し、その配下に時刻順（降順）でフラットなタイムラインを表示する。

### 画面レイアウトイメージ
```text
+---------------------------------------------------+
| 🏠 戻る             イベント履歴                  |
+---------------------------------------------------+
| 📅 2026-10-26                                     |
|   🎥 08:13:00  記録 [▶ 再生] [📤 共有]             |
|   🔊 08:10:11  音量 (振幅: 2,400)                 |
|   ⚠ 08:10:10  減速 (1.5秒 / 22km/h)              |
|   🚗 08:10:05  接近 (感度: 70% | 20km/h)          |
|   🎥 08:10:00  記録 [▶ 再生] [📤 共有]             |
|                                                   |
| 📅 2026-10-25                                     |
|   🚗 15:01:12  接近 (感度: 70% | 18km/h)          |
|   💥 15:01:10  衝撃 (3.4G)                        |
|   🎥 15:01:00  記録 [▶ 再生] [📤 共有]             |
+---------------------------------------------------+
```

---

## 2. 🔤 アプリ全体におけるイベント種類の並び順の完全統一

アプリ内のすべての画面（常時表示画面のスライダー、構造化件数サマリー、ライド結果サマリー、設定画面のCSVデバッグ設定等）において、イベント種類の表示順序は必ず以下の規約（**接近 ➔ 減速 ➔ 衝撃 ➔ 音量**）で**完全統一**する。

1. **`APPROACH`** (接近)
2. **`DECELERATION`** (減速)
3. **`COLLISION`** (衝撃)
4. **`SOUND`** (音量)

### 各画面での適用イメージ
- **常時表示画面のスライダー**:
  - `接近 70%      28件`
  - `減速 1.5秒     3件`
  - `衝撃 3.0G      0件`
  - `音量 5000      7件`
- **構造化件数サマリーカード**: `[ 🚗 接近 ]` ➔ `[ ⚠ 減速 ]` ➔ `[ 💥 衝撃 ]` ➔ `[ 🔊 音量 ]`
- **ライド結果サマリー**: 接近 ➔ 減速 ➔ 衝撃 ➔ 音量 の順で定量指標（件/km, 件/h）を縦並び表示。
- **設定画面 (CSVデバッグ)**:
  - ☑ 接近検知CSV
  - ☑ 減速検知CSV
  - ☑ 衝撃検知CSV
  - ☑ 音量検知CSV
